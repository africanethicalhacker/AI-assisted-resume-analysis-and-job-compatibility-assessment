# Chapter 3: Problem Statement and Objectives

## 3.1 Problem statement
Existing screening approaches (1) match shallowly, (2) are opaque, (3) handle sensitive data and untrusted documents with weak
security, and (4) present unvalidated weights as objective. The problem is to build a resume and job compatibility system that is
semantically capable, explainable, secure by design and empirically validated.

## 3.2 Aim
To design, implement, secure and evaluate an explainable hybrid NLP and machine-learning platform for resume analysis and job
compatibility that acts as decision support.

## 3.3 Objectives
1. Secure upload and parsing of PDF and DOCX resumes with evidence-preserving extraction.
2. An extensible skill taxonomy with explicit and inferred skills.
3. Job-description analysis that never assumes a requirement is mandatory without textual support.
4. TF-IDF, Sentence-BERT and structured matching in a configurable weighted model.
5. Skill-gap analysis and evidence-based role recommendations.
6. A dashboard and PDF reports with traceable scoring.
7. Integrated application, file, data and AI security, verified by documented tests.
8. Six reproducible experiments reported with their limitations.
9. Complete academic documentation for the viva.
