# Chapter 12: Results and Discussion

Insert `docs/report/results_auto.md` here after running the experiments (`python -m experiments.make_report_tables`).

For each experiment write:
1. What was measured, on which data, and with which settings.
2. The table with confidence intervals.
3. What the result does and does not show. Say plainly if the hybrid model did not beat a baseline.
4. Threats to validity: dataset size and representativeness, label subjectivity, synthetic-data circularity, single machine for timing.

Do not quote any figure that is not in a results file.
